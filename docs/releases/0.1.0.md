# 0.1.0 release record

## Status

**BLOCKED — not published.** This is a preparation record, not a release
announcement, tag, or artifact.

## Blocking evidence

T09 has not yet proved host metadata round-trip, `saveMany`
partial-versus-atomic behavior, or the host sign semantics for Revolut activity
amounts. Those proof items must close before a release can be approved.

## Future artifact convention

The approved release artifact will be named
`wealthfolio-revolut-importer-0.1.0.zip`. Its checksum will be recorded in the
same release's `SHA256SUMS`; consumers must verify the ZIP before installation.
Once published, the version tag and artifacts are immutable.
