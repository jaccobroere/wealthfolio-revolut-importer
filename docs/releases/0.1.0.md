# Revolut Importer 0.1.0

## Highlights

- Initial Wealthfolio 3.6.1 addon for the Revolut investment CSV schema.
- Added explicit ticker review with account-scoped mappings.
- Added strict validation for currencies, amounts, quantities, FX rates, and
  supported activity types.
- Added duplicate and overlap protection plus reconciliation diagnostics.
- Added deterministic addon packages, checksums, and release validation.

## Compatibility

- Wealthfolio 3.6.1
- Revolut investment CSV schema v1

See the [installation guide](../INSTALL.md) and [input format](../FORMAT.md)
before importing.
