# Revolut Importer 0.2.3

## Highlights

- **More reliable imports.** Canonical activities returned by Wealthfolio's
  import check are preserved for saving, and ticker mappings remain scoped to
  the selected account.
- **Improved CSV upload.** The first step now uses a responsive, keyboard
  accessible drag-and-drop surface aligned with the DEGIRO importer.
- **Simpler releases.** Release publication validates the public fixture suite,
  package contents, and deterministic artifacts without a self-attested local
  result.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
- Revolut investment CSV schema v1
