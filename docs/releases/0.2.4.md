# Revolut Importer 0.2.4

## Highlights

- **Editable stale mappings.** Remembered mappings that no longer match the
  current market search now show replacement choices and a scoped removal
  action.
- **Recoverable import flow.** Search, retry, start-over, and mapping-review
  actions ensure a blocked state is never a dead end.
- **Clear host failures.** A host-level bulk-write rejection is shown as a
  batch result and can be returned to mapping safely.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
- Revolut investment CSV schema v1
