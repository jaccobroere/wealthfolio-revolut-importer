# Revolut Importer 0.6.1

## Fixes

- **Reliable mapping reset.** Mapping updates are now serialized for the
  selected account. Clearing remembered mappings verifies the host's saved
  document before resetting the screen, so an older in-flight update cannot
  restore a mapping after it was cleared.
- **Actionable, private import diagnostics.** Rejected imports now identify a
  missing destination account and returned validation fields where Wealthfolio
  provides them. Source values and host error text remain private, and the
  importer does not retry a write whose outcome is uncertain.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
