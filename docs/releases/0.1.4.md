# Revolut Importer 0.1.4

## Highlights

- Updated addon tests and manifest validation to expect manifest-declared
  navigation (`contributes.routes` and `contributes.links.sidebar`) instead
  of runtime `sidebar.addItem`.
- Updated `src/addon.tsx` to register only the route renderer via
  `ctx.router.add`; the sidebar link now comes from the manifest alone.
- Updated `scripts/validate-manifest.ts` to require and validate the
  `contributes` field.
- First release on the fully fixed CI/CD pipeline (Node 22, pinned action
  SHAs, correct pnpm ordering, runtime-computed attestation).

## Compatibility

- Wealthfolio 3.6.1
- Revolut investment CSV schema v1

See the [installation guide](../INSTALL.md) and [input format](../FORMAT.md)
before importing.
