# Revolut Importer 0.3.0

## Highlights

- **Chunked host writes for large Revolut statements.** Large Revolut
  statements (>=200 activities) no longer fail at the final submit step.
  The host `activities.import` call is now chunked (default 100 / chunk,
  configurable via `RunImportOptions.chunkSize`); per-chunk failures
  surface as per-row failures instead of a fatal, so a host payload cap
  or a single bad row no longer takes down a 200+ row batch. Only a
  complete host outage is fatal.
- **Host-sandbox rewriter fix.** The add-on's `api.activities.import(...)`
  call was being rewritten by the Wealthfolio 3.6.1 host sandbox's
  `es-module-lexer` rewriter into a
  `globalThis.__wealthfolioImport(...)` call, which the host then
  rejected as an unknown method. The add-on now dispatches via
  `Reflect.get` so the `import` identifier is not in the call position
  of the minified bundle. The 3.6.1 host image SHA is recorded in
  the source.
- **Metadata-version bump.** The metadata `IMPORTER_VERSION` was
  bumped from `0.1.0` to `0.2.0` so the new release is
  forward-distinguishable from prior `0.1.x` metadata on the host.
- **Expanded E2E coverage.** The disposable-host Playwright suite now
  includes a 250-row batch test that exercises the chunked-import path
  end-to-end against a real Wealthfolio 3.6.1 host.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
- Revolut investment CSV with English headers

## Validation gap (honest disclosure)

The `pnpm release:check` real-statement acceptance gate was **not** run
for this release because the user has not configured
`REVOLUT_ACCEPTANCE_CSV` and `REVOLUT_ACCEPTANCE_BASELINE` with paths
to a real Revolut statement. The standard `pnpm check` (format, lint,
type-check, unit tests, fixture privacy scan, build, manifest
validation) and the disposable-host `pnpm test:host` E2E suite (cash
import + 250-row chunked batch) both passed green. Users importing real
statements on this version are encouraged to spot-check a recent
statement before bulk-importing.
