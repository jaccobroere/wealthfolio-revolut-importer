# Revolut Importer 0.5.0

## Highlights

- **Re-importing a full history only adds what is new.** Before anything is
  written, every activity in the statement is compared with the activities
  already on the destination account — on type, day, currency and value
  (quantity for buys and sells, amount otherwise) — and the ones already there
  are skipped. Repeated identical rows are counted rather than collapsed.

- **Every trade and dividend is linked to its security.** Wealthfolio 3.6.1's
  import endpoint does not create securities, so activities for a ticker
  Wealthfolio did not know yet were stored with no security at all: they
  moved cash but never showed up in holdings. The importer now creates a
  missing security by writing one of its activities through Wealthfolio's bulk
  activity API, then imports the rest linked to it. An activity whose security
  cannot be created is reported as failed; it is never stored without its
  security.

- **Same-day repeats are no longer dropped.** Wealthfolio's import keeps only
  one activity per day, type, security and amount, so two equal top-ups on one
  day — or equal commission refunds on different tickers — lost all but the
  first. The second and later copies now carry a numbered comment (`#2`) and
  are all imported.

- **Cash totals reconcile.** Trades are sent with the cash-consistent price
  (`Total Amount ÷ Quantity`) instead of the rounded display price, so
  Wealthfolio's `quantity × price` equals the statement's total. Revolut's
  `FX Rate` is no longer forwarded: Wealthfolio reads it the other way round
  and booked foreign-currency trades' cash in EUR at that rate.

- **See what is already in Wealthfolio before importing.** The reconcile step
  shows how many activities are new and how many will be skipped, and lists
  account activities that need attention: extra copies to delete, and
  activities stored without a security (delete them and import again to
  re-create them linked). The Import button and acknowledgement state the
  number of new activities.

- **Tickers in review and reconcile.** The review table has a security column
  and the net-position table shows the Wealthfolio ticker and exchange each
  Revolut ticker is mapped to.

## Permissions

This release adds `activities.saveMany`. It is used only to create securities
Wealthfolio does not know yet (one activity per new security). All other
activities still go through `activities.import`. The add-on never updates or
deletes existing activities.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
- Revolut investment CSV statements
