# Revolut Importer 0.4.0

## Highlights

- **Fix problem rows in the review step, without editing your CSV.** Any row
  in the review table now expands into per-row reviewer controls. A row can be
  **edited** — correct the Type, Total Amount, Ticker, Quantity or any other
  source column, with a live preview of exactly how the corrected row will
  validate — or **ignored**, which excludes it from the import. Previously a
  single unsupported `Type` or malformed value meant editing the source file by
  hand and starting the import over.

  Both actions are deliberate, per-row, and fully accounted for: an ignored row
  becomes a new `ignored` outcome with its own review category rather than
  disappearing, so the every-row-produces-exactly-one-outcome invariant still
  holds. Rows built from edited values are flagged `Edited` in the review
  table, and the reconcile step shows how many rows you changed before you
  acknowledge. Nothing is ever written back to your CSV.

- **An edit can no longer smuggle in an unmapped security.** Correcting a row
  can turn a previously-invalid row into a valid trade carrying a ticker the
  mapping step never saw. Ticker entries are now re-derived after every rebuild:
  a newly-introduced ticker arrives unresolved and blocks Import until it is
  confirmed against the host, while tickers you already confirmed keep their
  resolution.

- **Import payload correctness.** Drafts, source fingerprints, and source row
  numbers are now derived from a single filtered list (`buildImportPayload`).
  They are consumed positionally downstream, so deriving them from different
  lists could pair an activity with another row's idempotency key once any row
  was excluded.

## Other changes

- Import is blocked when a batch would write nothing at all.
- Import is blocked, with an explanation, if re-running validation after a
  reviewer decision fails — previously the failure was silent and the
  pre-edit batch remained importable.
- The reconciliation report is now computed by an effect whenever the reconcile
  step lacks one, replacing a `queueMicrotask` ordering hack that could leave
  Import permanently blocked if a rebuild landed just after Continue was
  clicked. Continue is also disabled while a rebuild is in flight.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
- Revolut investment-statement CSV exports (strict 8-column schema)

No migration is required.

## Validation gap (honest disclosure)

`pnpm check` (format, lint, type-check, 153 unit tests, fixture privacy scan,
build, manifest validation) passed green. Not run: the disposable-host
`pnpm test:host` Playwright suite. Users are encouraged to spot-check a recent
statement before bulk-importing, and to look carefully at the reconcile-step
summary of any rows they ignored or edited.
